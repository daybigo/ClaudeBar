Instalación y actualizaciones

Instalador NSIS por usuario (sin admin) o una línea en PowerShell. El instalador ya empaqueta WebView2Loader.dll para que abra en cualquier PC.

Privada por diseño

Todo se lee localmente: el token de Claude Code en ~/.claude, los logs de uso y las cuotas. Sin telemetría, sin servidores de terceros. Audítala ↗

Cómo saca los datos

Sesión/semanal/Sonnet desde api.anthropic.com/api/oauth/usage; costo y tokens analizando tus *.jsonl locales con precios estilo ccusage. Codex y Antigravity, de sus sesiones locales.

Requisitos

Windows 10/11 con WebView2 (ya viene en Win 11) y Claude Code instalado e iniciado sesión. Hecha con Rust + Tauri sobre el WebView2 nativo — sin Chromium empaquetado.
